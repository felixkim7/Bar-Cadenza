# Example records

These records demonstrate proposed field names and units. They are not final cast canon, approved recipes or production assets. No runtime loader currently exists. T010 implements validation contracts; T012 creates reviewed working fixtures. Keep `example_only` files out of production catalogue discovery.

Ingredients and recipe use integer microliters. Asset IDs are planned identifiers without runtime images. Glass/technique IDs become validated registries in T010/T017. Character private facts must not appear in the player journal or unexplained score deductions.
