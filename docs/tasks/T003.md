- IME design (after D021): TEXTEDITING sets the inline composition preview (no underline); TEXTINPUT commits. Enter sends at once and Shift+Enter inserts a line break, including the syllable being composed. If Enter arrives before the IME commit, the action waits for the commit in the same batch (dropped, never doubled, if it doesn't come). Backspace/Delete are ignored for the whole batch in which the IME was active, and arrows while composing, so an IME Backspace never also deletes committed text. Held keys repeat via `pygame.key.set_repeat(500, 33)` (Windows default delay/rate; pygame's repeat is off by default). Draft capped at 500 chars; pasted CR/LF become line breaks, tabs become spaces, control chars are dropped. Wrap breaks after spaces (English words, Korean eojeol), hard-breaks overlong runs, honors newlines. SDL_IME_SHOW_UI=1 enables the native candidate list (Hanja); the IME rect follows the caret.
