# Character creation specification v1 — decision-gated

Generate only after O005 scope and O010 population rules are selected. Produce one adult profile using the schema, chosen world/history policy, content boundaries, required language fields, and approved portrait strategy. Avoid repeating recent characters' jobs, emotional situations and voices.

Include stable facts, current situation, private/revealed facts, tastes, speaking style, appearance specification and potential follow-up. Give interests and contradictions beyond a problem. Distinguish people through posture, costume, hair, accessories and color blocking; avoid making the entire cast identically glamorous.

Appearance follows ART_DIRECTION.md. Do not generate a portrait file path or approved asset ID that does not exist; propose a descriptor for the portrait resolver. No gameplay rewards or unsupported species assumptions. Return a candidate for validation; acceptance, ID allocation and persistence belong to game code.
