# Memory update specification v1

Summarize a completed encounter from supplied transcript/actions and previous memory. Preserve established identity, revealed preferences, unresolved topics and explicit promises. Every new confirmed fact needs source turn/event IDs. Label uncertain interpretation as inference or omit it; never silently promote it to fact.

Do not copy private profile facts into the player-known summary unless the transcript reveals them. Distinguish what the customer said from what the player said. Return compact structured updates in the specified contract; application validates references and stores accepted facts transactionally. Do not edit old transcripts or award rewards.
